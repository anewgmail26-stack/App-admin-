Setup Instructions

Use only Firebase Web SDK client config. Do not paste any private key into this file.

1. Paste Firebase Web Config

Open Firebase Console, go to Project settings, then General, then Your apps. Create or select a Web app and copy the firebaseConfig object.

Replace the placeholder firebaseConfig inside this file. Keep this database URL:

https://my-new-vpn-88725-default-rtdb.asia-southeast1.firebasedatabase.app

2. Open Locally

After saving the config, double-click admin.html or open it in Chrome. If your browser blocks local scripts, run a small local server:

python -m http.server 8080

Then open http://localhost:8080/admin.html.

3. Deploy to Firebase Hosting

From this folder, install and initialize Firebase Hosting if needed, then deploy:

npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy

Choose this folder as the public folder if you want to host only this file, or place admin.html in your configured hosting folder.

4. Test With a VLESS Link

Go to Add V2Ray, paste a vless:// link into Raw link, then click Parse Raw Link or just paste and wait. Check protocol, host, port, UUID, network, security, SNI, path, and header host.

Save it, then verify the record appears under servers/public in Realtime Database.

5. Update Android App

Open your Android VPN app, press its Updates or Refresh button, and confirm it reads the latest list from servers/public.

If the app does not update, check that the app reads the same database URL and path.

Rules Expectation

The Android app can read servers/public. This admin page can write only if your database rules allow this Web SDK client to write.

Quick testing can use open writes briefly. For production, restrict writes to authenticated admin users.

{
  "rules": {
    "servers": {
      "public": {
        ".read": true,
        ".write": true
      }
    }
  }
}
